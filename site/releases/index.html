Release notes

A clean first release.

Version 1.0.0 establishes the offline, local-first foundation and a complete day-to-day spending workflow.

1.0.0 · September 20, 2026

Daily tracking

  • Safe-to-spend Today view with cycle progress and recent activity.
  • Income and spending capture with edit, filter, search, and delete flows.
  • Planning for income, fixed commitments, savings, and daily allowance.

Cards and input

  • Credit-card balance, limit, statement, due-date, and payment planning.
  • Bank SMS paste assistant with a review-before-save workflow.

Ownership and access

  • Validated JSON backup and restore plus CSV transaction export.
  • English and Arabic interfaces with right-to-left support.
  • Installable PWA assets, isolated service-worker cache, and offline app shell.

Quality

  • Responsive desktop, iPhone portrait, and iPhone landscape coverage.
  • Keyboard and screen-reader semantics, reduced-motion support, and automated accessibility checks.
  • Public evidence page and machine-readable test summary.

Compatibility

The primary mobile target is current Safari on iPhone. The app is also tested in current Chromium on desktop and in Playwright WebKit using iPhone 13 portrait and landscape profiles. Private browsing and browsers configured to discard website data are not suitable for durable storage.
