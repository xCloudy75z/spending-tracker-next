Migration and recovery

Keep control when you change devices.

Because there is no account or cloud sync, a backup file is the bridge between browsers and phones.

Before you start: export a fresh JSON backup from the old installation. Do not clear browser data until the restored records have been checked.

Move the complete app state

  1. On the old device, open Settings in the app and choose Download backup.
  2. Move the downloaded JSON file using a secure method you control.
  3. Open Spending Tracker on the new device once while online, then add it to the home screen if desired.
  4. Choose Restore backup and select the JSON file.
  5. Review Today, Activity, Plan, and Cards before removing the old copy.

Restore safety

The app validates the file structure and schema before replacing current data. An invalid or unsupported file is rejected without partially importing it. Restoring a valid backup intentionally replaces the current local app state, so create a backup of the destination first if it already contains useful records.

CSV is for analysis, not restore

CSV export is a human-readable transaction table for spreadsheets and archives. It does not contain the full plan, settings, cards, or metadata required for a complete restore. Use JSON for migration and disaster recovery.

Coming from the original app

This version uses a new, validated data model and does not silently read or delete the original app’s browser storage. Keep the original installation intact. If it can export compatible JSON, import a copy and review the result; otherwise preserve the old export as a record and start the new tracker with your current balances and plan.
